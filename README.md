# Componente de Upload de Imagem
<img width="592" height="507" alt="image" src="https://github.com/user-attachments/assets/0a16e142-aef2-4378-aaeb-12bb10c21143" />



Este é um componente de upload de imagem que desenvolvi focando em **simplicidade**, **modernidade** e **experiência real de uso**.
Ele permite fazer upload de imagem de forma intuitiva, seja clicando ou arrastando arquivos, e exibe uma prévia elegante com opções de substituição e remoção.

O objetivo deste projeto é oferecer uma solução **prática e reutilizável**, com código limpo e totalmente separado em **HTML, CSS e JavaScript**, ideal para integrar em qualquer sistema, portfólio ou aplicação web.

---

##  Funcionalidades

* Upload por **clique** ou **arrastar e soltar**
* **Pré-visualização automática** da imagem enviada
* Botões para **substituir** ou **remover** o arquivo
* Interface pensada para ser simples, intuitiva e acessível
* Compatível com **JPG, PNG e GIF**
* Arquitetura separada em **HTML | CSS | JS** para fácil manutenção

---

## Tecnologias:

* **HTML5** – Estrutura do componente
* **CSS3** – Estilização moderna e responsiva
* **JavaScript** – Lógica de preview, drag & drop e controle dos botões

---

## 📁 Estrutura do Projeto

```
/upload-imagem
│── index.html
│── style.css
│── script.js
```

Cada arquivo tem uma função clara:

* `index.html` → estrutura do componente
* `style.css` → responsividade e animações
* `script.js` → funcionamento interno

---

## ▶️ Como executar

Para rodar, não precisa instalar nada.
Basta abrir o arquivo:

```
index.html
```

em qualquer navegador moderno.
Você já verá o componente funcionando — drag & drop incluído.

---

## 🛠️ Como reutilizar no seu projeto

Se quiser usar o componente em outro site, é só:

1. **Importar o `style.css`**
2. **Importar o `script.js`**
3. **Copiar o HTML** do componente para onde quiser
4. Pronto! Ele funciona imediatamente.

Totalmente plugável, sem dependências externas.
